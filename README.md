# Cobblemon Player XP Share

Adds a configurable share of **the experience the player gains** to the
Pokémon in their party: mob kills, experience bottles, furnaces, trading,
fishing, and so on. Not battle experience settlement.

At the default 300%, 1 player XP gives each target Pokémon 3 XP.

## Requirements

| | |
| --- | --- |
| Minecraft | 1.21.1 |
| Cobblemon | 1.6.0+ |
| Java | 21 |

## Settings

**Mods → Cobblemon Player XP Share → Config** (the file is
`config/cobblemon_player_xp_share-common.toml`).

| Option | Values | Default |
| --- | --- | --- |
| Sharing enabled | Enabled / Disabled | Enabled |
| Share ratio | 100% – 1000%, 100% steps | 300% |
| Sharing state | While sent out / While benched | While sent out |
| Whole team | Yes / No | No |
| Fainted Pokémon also gain XP | Yes / No | No |
| Send a notification when XP is shared | On / Off | On |
| Display type for multiple notifications | Merged / Frequent updates | Merged |

- **Share ratio** — share given to each target per 1 player XP. No 0% step; use
  the master switch instead.
- **Sharing state** — sent out only counts the Pokémon in battle (pick one with
  R + mouse wheel); benched shares with the party members that are away.
- **Whole team** — No: only the selected Pokémon. Yes: every eligible one. The
  text under it changes with the sharing state.
- Notifications appear in the action bar. Merged counts a burst together;
  Frequent updates refreshes on every share.
